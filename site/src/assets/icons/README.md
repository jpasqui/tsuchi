# Icons

The icons here are from the Game Icon Pack by Nieobie, released
under Creative Commons Zero (CC0 1.0). The pack is at
https://github.com/Nieobie/game-icon-pack.

To add an icon, copy its file from the pack's `svg/padding` folder into this folder. A page
uses it by its name without `.svg`: `<IconCard icon="folder" ...>`.

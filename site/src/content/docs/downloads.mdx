---
title: Packages
description: The framework and SDK packages used by the installation guides.
---

Download Tsuchi from the [releases on GitHub](https://github.com/jpasqui/tsuchi/releases). Extract the
framework archive, then follow [Install Tsuchi](/players/install-tsuchi/)
or [Install on a console](/players/install-console/).

To use the SDK archive, follow [Build a compiled mod](/develop/compiled-mod/). Use the SDK that matches your Tsuchi
release, and keep its headers and support files together. To write Lua or JavaScript
mods, you only need a text editor.
